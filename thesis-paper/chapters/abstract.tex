Abstract

% This thesis presents the design and implementation of KVRaft, a fault-tolerant distributed key-value store built upon the Raft consensus algorithm. In modern distributed computing, maintaining data consistency across a cluster of independent nodes remains a significant challenge due to network partitions, message delays, and hardware failures.

% The core of this work involves implementing the three fundamental pillars of Raft: Leader Election, Log Replication, and Safety, ensuring the system adheres to Linearizable consistency. Unlike traditional academic implementations, this project utilizes gRPC for efficient, strongly-typed inter-node communication and features a Replicated State Machine (RSM) layer that decouples consensus logic from application state.

% A key contribution of this thesis is the exploration of cross-platform interoperability. While the server cluster is implemented in Go, a multi-language Client SDK (Clerk) was developed in both Go and Java to demonstrate the flexibility of the architecture. Furthermore, the system includes an automated orchestration environment for cluster management and failure testing. The evaluation demonstrates that the implementation successfully maintains high availability and data integrity even during significant node failures, providing a robust "source of truth" for distributed applications.
